SubagentRunsBlock.tsx: the block keeps its place under the turn's explanation. Columns become model and requests, tokens and priced cost; the totals line reads main agent, subagent runs, turn.
Rules on every frame
Claude Code has tokens and a priced cost (tokens × the price book, per run model); it has no AI Credits. Every figure here is tokens or priced USD, and the AI Credits cell stays an em dash or n/a with the reason.
Unknown is never shown as 0: an unknown turn shows em dashes, a dashed marker and the reason; a known figure never leaves a run out.
The marker is a fork glyph with an accessible name that says the words; color is never the only signal. It appears only when a run exists.
Frames: Light (Industry tokens, standalone app) and Dark Modern (the VS Code webview's mapped tokens). Data is invented.
