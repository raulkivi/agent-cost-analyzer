# "Connect an agent" mock-ups (standalone app)

**Last changed:** 2026-11-19 · **Source:** https://github.com/raulkivi/agent-cost-analyzer

Boards for task MC10 in [mcp-client-setup.md](../../mcp-client-setup.md) §10 (panel design: §5.6, decision D1). **Drawn 2026-11-19, awaiting owner approval** before any UI code (MC12).

Same `.dc.html` format as [../monthly-allowance-standalone/](../monthly-allowance-standalone/README.md), listed in `canvas.json`. They reference `./support.js`, which isn't in the repo; every state is static markup, so each board also renders in a plain browser. All content is generic: paths use `~`, the version is the placeholder `1.1.0`, no figures from real data.

Every board shows the standalone ledger theme twice, **light** then **dark**, with the real tokens from `packages/web/src/theme.css`: Commit Mono for the UI, Source Serif 4 for prose, hairline borders, square corners. Standalone app only; the VS Code extension panel has no such button.

## What the panel is

A header button opens a dialog. The dialog only **shows** setup information from a read-only `GET /api/mcp/setup`. It never writes a file and never runs a command (D1); the terminal command `npx agent-cost-analyzer mcp install` is the only writer. The recommended one-liner needs no API data, so it shows even when the API fails.

## Each tab

- **Recommended: one command.** `npx agent-cost-analyzer mcp install --client <id>` with Copy.
- **Or set it up by hand.** The client's own command (Claude Code, Codex CLI, Gemini CLI) or the JSON snippet with its config file path (Claude Desktop and Cursor under `mcpServers`; VS Code and Insiders under `servers`), each with Copy. Paths are those of the server's OS (Linux drawn).
- **Cursor only:** an "Add to Cursor" link to the `cursor://` install URL.
- **A short note** where it matters: restart Claude Desktop afterwards; skip VS Code (and Insiders) if the AI Credits Analyzer extension is installed; Codex has no remove command.

## Regenerating

The boards and PNGs are generated by scripts kept outside the repo (Playwright Chromium, the app's bundled fonts); only the output is committed. Edit the boards only through that generator, or redraw by hand.
