Dialog: Claude Code and Cursor, ledger light

Default tab: Claude Code

Connect an agent

Let your coding agent ask this app about its own costs. This panel only shows commands. Run them in a terminal; nothing here changes your files.

Claude Code

Recommended: one command
npx agent-cost-analyzer mcp install --client claude-code
Run it in a terminal. It shows what it will change and asks before writing.
Or set it up by hand
Run in a terminal:
claude mcp add --scope user agent-cost-analyzer -- npx -y --prefer-offline agent-cost-analyzer mcp

Adds the server for every project (user scope). Run it in any terminal.

Cursor tab: JSON snippet, and "Add to Cursor"

Connect an agent

Let your coding agent ask this app about its own costs. This panel only shows commands. Run them in a terminal; nothing here changes your files.

Cursor

Recommended: one command
npx agent-cost-analyzer mcp install --client cursor
Run it in a terminal. It shows what it will change and asks before writing.
Or set it up by hand
Add to ~/.cursor/mcp.json:
{
  "mcpServers": {
    "agent-cost-analyzer": {
      "command": "npx",
      "args": ["-y", "--prefer-offline", "agent-cost-analyzer", "mcp"]
    }
  }
}
Or use the install link
Add to Cursor
Opens a cursor:// link in the Cursor app.

The install link opens Cursor and asks you to confirm.
