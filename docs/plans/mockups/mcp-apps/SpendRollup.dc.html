Board notes

What the host owns, what the brand owns

  • Host (its recorded variables): page and card backgrounds, text, borders, the fonts, radii, and the severity colours.
  • Brand (brand.css, follows hostContext.theme): the 16 px mark, the kicker, the four corner marks, and the data marks: bars, columns, the context bar, selected and event markers.
  • The view background is transparent; the card sits on the host's chat surface. No brand fill on large areas.
  • Headings use local("Barlow Condensed") only. A0 found it absent in both hosts, so the boards draw headings in the host font.
  • In-place drill-down: clicking a top session calls get_session_cost through the host and swaps this card to U1, with "Back to spend this week" restoring the rollup. The model never sees the result.
  • "40/42" beside a session total marks partial coverage; the tooltip reads "known for 40 of 42 turns".

Host colours on these boards

  • VS Code sends var(--vscode-*) references for all 76 variables. The boards resolve them to the default Light Modern, Dark Modern and Dark High Contrast values (inferred, not recorded). Fonts: the editor's UI font stack.
  • Claude Desktop sends concrete light-dark() pairs; the boards use the recorded light or dark half. Its anthropic-sans font arrives through hostFonts; the boards draw its system fallback.
  • VS Code reports Dark High Contrast as dark with no HC flag, so the brand uses its dark ramp there; only the host variables change.
