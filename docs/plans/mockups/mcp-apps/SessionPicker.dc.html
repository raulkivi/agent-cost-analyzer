Board notes

U5: what to check

  • What a click sends. Only "Analyse session 7f3a9c2e": the fixed template and the id. The last two frames show the chat after the click, with the same text as the user's next message.
  • Titles are logged text. They are displayed (truncated, with the full title in a tooltip) and never forwarded. The hint line under the list says so.
  • Row content. Title, short id, start, turns, model and repository (the extension has attribution; the standalone app adds the project on the same line when set). No cost is shown: the list tool returns none.
  • After the click. The row's button reads "Sent" with a check and is disabled; the view calls nothing and gets no answer. The model replies with its normal analysis.
  • Without sendMessage the button is hidden (see the states board).
