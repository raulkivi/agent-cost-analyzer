Labels

Severity is meaning, not brand

  • Severity uses the host's semantic colours (--color-text-danger, -warning, -info) and a shape (diamond critical, triangle high, dot medium, ring low and info) plus the written word, so it never depends on colour alone.
  • The kind and severity filters call list_findings again; the tiles keep the unfiltered counts and dim the excluded severities.
  • Evidence is collapsed by default and already redacted by the tool. Opened, it is plain text in the card; it is never sent to the chat or the model context.
  • An observed price change carries "inferred".
  • In VS Code Light Modern errorForeground (#f85149) is used only for the mark, not text: as text on white it would be under 4.5:1. A6's contrast tests check this against the recorded sets.
