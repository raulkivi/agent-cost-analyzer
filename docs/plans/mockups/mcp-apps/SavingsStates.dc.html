Board notes

States: what each says

  • Loading (1). Skeleton rows with a status line; aria-busy on the region. No Cancel: the host owns the call, and the view has no way to stop it.
  • Empty window (2). Says what is missing and how to widen it in the chat. No button, because the view sends no message other than "Analyse session <id>".
  • Every amount unknown (3). Rows say "Not priced" with the reason; they are unranked and nothing is shown as 0.
  • No trace for a provider (4). The note above the rows names the provider and the check that was skipped; Not analysed repeats it with session counts.
  • Simulated off (5). The section stays in place so the owner knows replays exist, and says how to ask for them.
  • Error (6). Names the tool and the cause, with Retry. A failed drill-down (not drawn here, as on the Increment 2 board) keeps its Back control.
Narrow and accessibility

At 360 px

  • Rows (7, 8). The card goes to one column; each row reads title, subject, labels, coverage, then the amount and bar. Rank circles shrink to 20 px; the expanded detail loses its two-column facts.
  • Targets. Row buttons and "Open cost" / "Open replay" buttons sit inside full-width rows about 60 px tall (the buttons are 22 px high, as on the standalone Detail board). The same keyboard path as the wide frames; no horizontal scroll at 360 px.
  • Colour. Hatching and the written "up to" carry the range; dashed tags carry inferred, estimate and Simulated, in all four themes.
