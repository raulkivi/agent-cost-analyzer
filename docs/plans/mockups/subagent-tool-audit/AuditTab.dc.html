Audit tab · subagent calls, split and runs table

SessionAuditPanel.tsx (web and the extension webview): KPI sub-line, a Calls by agent split, an Agent filter and column, a Subagent runs table. Data from get_session_audit: byOrigin, subagentRuns.
Rules on every frame
Counts include subagent calls (D1); the split shows Main agent + Subagent runs = Tool calls. Unknown is never 0: an unread run shows an em dash, a dashed frame and its reason.
A subagent row carries the fork glyph from step 10.19 and the agent name (the label only when there is no agent name); the glyph has an accessible name, so color is never the only cue.
Narrow (320 px): table rows become stacked cards with the Agent on its own line; exit code and evidence sit under the command at both widths.
Four states: Known, Unread runs, Matched by time, Nested (Agent Host). All data is invented.
