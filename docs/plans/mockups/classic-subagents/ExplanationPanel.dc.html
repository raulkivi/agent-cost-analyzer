Explanation panel · Subagents this turn

ExplanationPanel.tsx: a block between the explanation sentence and Tool calls this turn. One row per run with label and agent, model, requests and AI Credits. describeTurnUsage names the share in the sentence.
Rules on every frame
Unknown is never shown as 0: an unknown turn shows an em dash, a dashed marker and the reason; a 0.00 run is a known figure the log records.
The marker is a fork glyph with an accessible name that says the words; colour is never the only signal. Marker and 0.00 rows appear only when a run exists.
Frames: Light (Industry tokens, standalone app), Dark Modern and High Contrast (the VS Code webview's mapped tokens). Data is invented.
An unknown run keeps its row (dashed outline, em dash, the §4.3 reason in the row). The totals line keeps the main agent's own figure (D10), because the turn total cannot be subtracted when a run is unknown.
