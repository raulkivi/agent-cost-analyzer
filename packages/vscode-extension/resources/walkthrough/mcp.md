# Ask Copilot about your costs

**Coming in a later version.**

AI Credits Analyzer will be able to answer questions such as "what did my
last session cost?" from Copilot Chat, through a **read-only MCP server**
that reads the same local logs as the analyzer.

- It stays **off** until you turn it on in settings.
- It returns redacted session data to the model you chat with, which is why
  it is opt-in.
- Nothing is shared with any model today.
