**Last changed:** 2026-11-15 · **Source:** https://github.com/raulkivi/agent-cost-analyzer

An alias of [`agent-cost-analyzer`](https://www.npmjs.com/package/agent-cost-analyzer) (with a z). It depends on that package and runs the same app, so a misspelled `npx` command still works. `agent-cost-analyzer` is the canonical name; use it in scripts and docs.

Run it with `npx agent-cost-analyser` <!-- codespell:ignore analyser -->

The options, the `mcp` command and everything else are the real package's. Needs Node.js 22.18 or newer.
